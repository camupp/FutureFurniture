# Замер кухни — визуализатор

Планшетный веб-инструмент для замерщиков мебельных компаний: за 5–10 минут на объекте
ввести геометрию помещения, расставить блоки кухни и показать клиенту 3D-концепт.

Это **инструмент визуализации и согласования**, а не CAD-система: чертежи для производства
остаются за конструктором в офисе. Полное описание продукта — в [product.md](product.md),
устройство кода — в [ARCHITECTURE.md](ARCHITECTURE.md).

## Что уже работает

- **План помещения** — рисование стен на холсте с шагом сетки 10 мм, привязкой углов к 90°
  и притяжением к существующим вершинам. Длина и толщина стены правятся числом в мм;
  масштаб на планшете меняется жестом двумя пальцами.
- **Проёмы и коммуникации** — ПКМ на компьютере или долгое нажатие на планшете открывает
  контекстное меню стены или пола. Окна, двери, вода, газ, розетки и вентиляция крепятся
  к стене, канализацию и другие напольные выводы можно поставить в любой точке пола.
  В 2D и 3D выводы имеют разные условные обозначения и физическую ориентацию.
- **Вид спереди** — второй 2D-холст показывает мебель, проёмы и инженерные выводы;
  блоки и выводы можно перетаскивать по горизонтали и высоте.
- **Каталог блоков** — шкаф напольный, навесной, пенал, столешница, мойка, плита.
  У каждого блока правятся габариты, цвет, поворот и координаты X / Y / Z; геометрия
  пересчитывается сразу в 2D и 3D.
- **Умная расстановка** — брошенный у стены блок разворачивается по ней и встаёт вплотную,
  однотипные блоки стыкуются без зазора, а попавший на занятое место съезжает в ближайшее
  свободное. Мебель также отталкивается от окна и от сектора открывания двери.
- **Магнит по высоте** — мойка и плита врезаются в столешницу заподлицо, столешница
  садится на тумбы.
- **3D-сцена** — стены с реальными вырезами под окна и двери, пол, инженерные выводы и
  мебель, орбитальная камера. Стена между камерой и комнатой автоматически становится
  полупрозрачной.
- **Инженерные связи** — вода и канализация считаются подключёнными к единственной
  нижней базе-хосту с мойкой, газ — к базе с варочной панелью. Подключённые выводы
  отмечаются зелёным, а отсутствующая
  или несовместимая связь — жёлтым предупреждением, но не геометрической ошибкой.
- **Проверка** — красным подсвечивается блок, вышедший за контур стен или пересекающийся
  с другим блоком, окном, дверью либо сектором её открывания. Пересекающиеся проёмы и
  выводы за контуром комнаты также подсвечиваются.
- **Экспорт** — кнопка «Скриншот» сохраняет кадр 3D-сцены в PNG.
- **Сохранение** — проект переживает перезагрузку (localStorage), работает офлайн.

## Запуск

Нужен Node.js 20+ (проверено на 26.9) и npm.

```bash
npm install
```

```bash
npm run dev
```

Дев-сервер поднимется на http://localhost:5173.

Те же операции доступны короткими командами Make:

```bash
make setup-all
make dev
```

`make help` показывает полный список целей. Для ежедневной проверки достаточно
`make check`, а перед отправкой большой ветки — `make ci` с браузерными тестами.

### Команды

| Команда                 | Что делает                                             |
| ----------------------- | ------------------------------------------------------ |
| `npm run dev`           | Дев-сервер Vite с HMR                                  |
| `npm run build`         | Проверка типов и продакшен-сборка в `dist/`            |
| `npm run preview`       | Локальный просмотр собранного `dist/`                  |
| `npm run typecheck`     | Проверка типов приложения и тестов                     |
| `npm run lint`          | Статический анализ Oxlint                              |
| `npm run lint:fix`      | Безопасные автоматические исправления Oxlint           |
| `npm run format`        | Форматирование исходников и тестов через Prettier      |
| `npm run format:check`  | Проверка форматирования без изменения файлов           |
| `npm test`              | Модульные и интеграционные тесты Vitest                |
| `npm run test:watch`    | Те же тесты в режиме наблюдения                        |
| `npm run test:coverage` | Тесты и HTML-отчёт о покрытии в `coverage/`            |
| `npm run test:e2e`      | Пользовательские сценарии Playwright в Chromium        |
| `npm run check`         | Типы, быстрые тесты и продакшен-сборка                 |
| `npm run check:all`     | Полная локальная проверка, включая браузерные сценарии |

### Автотесты

Быстрый набор проверяет геометрию, проёмы, коммуникации, умную расстановку,
валидацию и операции стора, включая загрузку проекта старого формата. Браузерный набор
проверяет наиболее важные сквозные действия: контекстное добавление окна и напольного
вывода, сохранение после перезагрузки, инженерные связи базы с мойкой и переключатель
умной расстановки.

Перед первым браузерным прогоном установите Chromium:

```bash
npx playwright install chromium
```

Для обычной разработки достаточно `npm run check`. Перед отправкой большой функциональной
ветки используйте `npm run check:all`. Те же проверки запускаются в GitHub Actions на
каждый push и pull request.

## Стек

| Слой           | Технология                                        |
| -------------- | ------------------------------------------------- |
| Сборка         | Vite + TypeScript                                 |
| UI             | React 19, Tailwind CSS 4                          |
| 2D-редакторы   | Konva через react-konva                           |
| 3D             | Three.js + React Three Fiber + drei               |
| Состояние      | Zustand (+ `persist` в localStorage)              |
| Схемы и валидация | Zod                                            |
| Тесты          | Vitest + Playwright                               |

Бэкенда нет и в этой итерации не планируется — вся логика на клиенте.

> **Версии React зафиксированы на `~19.2` намеренно.** `@react-three/fiber@9` требует
> `react >=19 <19.3`, а `react-konva@19.3` — уже `^19.3`. Совместимая пара — React 19.2
> и `react-konva@~19.2`; при обновлении React эти два пакета нужно двигать вместе.

## Структура

```
src/
├── app/App.tsx              # раскладка, тулбар, переключатели видов
├── modules/
│   ├── room-editor/         # вид сверху: стены, блоки на плане
│   ├── elevation-editor/    # вид спереди (высоты)
│   ├── scene-3d/            # Three.js сцена и экспорт кадра
│   ├── parametric-blocks/   # геометрия блоков из параметров
│   ├── furniture-library/   # каталог блоков
│   ├── properties/          # панель свойств выделенного объекта
│   └── validation/          # правила корректности расстановки
└── shared/                  # типы, стор, геометрия, единицы измерения
tests/
├── unit/                    # изолированные проверки предметной логики
├── integration/             # совместная работа стора и сохранения
├── e2e/                     # пользовательские сценарии в Chromium
└── fixtures.ts              # общие фабрики тестовых данных
```
